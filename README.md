PDF Invoice Data Entry

Project Overview

In this project, I used a sample PDF invoice as the source document and manually entered the invoice data into Excel.

I created a table containing the invoice items, including the item description, tax rate, unit price, quantity, and total price.

I then calculated the values in Excel and checked them against the values shown on the original invoice.

I also created an invoice summary and performed Quality Control (QC) checks to verify that the entered and calculated data matched the source document.

Source Data

The source data was a sample PDF document containing an example invoice.

Tasks Completed

- Read data from a PDF invoice.
- Manually entered invoice data into Excel.
- Created a structured invoice items table.
- Calculated item totals in Excel.
- Compared calculated values with the source invoice.
- Created an invoice summary.
- Performed Quality Control checks.
- Verified the accuracy and consistency of the entered data.

Excel Structure

The Excel workbook contains:

- Invoice Items — invoice line items, calculations, and QC status.
- Invoice Summary — invoice information and Quality Control results.

Quality Control

Quality checks were performed to verify:

- item calculations,
- invoice totals,
- tax calculations,
- consistency between the source PDF and the Excel data.

Result

The invoice data was successfully entered into Excel and checked against the original PDF source document.
